分析引擎连接

本机

远程 Ubuntu 建议通过 SSH 隧道连接，不要将分析 API 直接暴露到公网。

如何连接远程 Ubuntu？
  1. 在 Ubuntu 上启动 CodeInsight 引擎，并保持监听 127.0.0.1:8001。
  2. 在 Windows 执行：ssh -N -L 18001:127.0.0.1:8001 user@ubuntu-host
  3. 将上方引擎地址改为 http://127.0.0.1:18001，再点击连接。
  4. 添加项目时填写 Ubuntu 上的绝对路径，例如 /srv/code/my-project。
